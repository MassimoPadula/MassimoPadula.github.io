FitLife - Fitness Tracker

Full-Stack Development

Project Overview

FitLife is a full-stack fitness tracking application that allows users to log workouts, sets, and reps while maintaining a streak feature to encourage consistency. The application provides personalized dashboards and an interactive calendar for planning workouts.

What I Built

I developed the complete application from front-end to back-end, implementing user authentication, workout logging functionality, and data persistence. The project features a modern, responsive UI and a scalable server architecture.

Technologies & Tools Used

React Tailwind CSS Node.js Express.js PostgreSQL Session-Based Auth REST API

Key Features

  • User authentication with session management
  • Workout logging system (sets, reps, exercises)
  • Streak tracking to encourage consistency
  • Personalized user dashboards
  • Interactive calendar for workout planning
  • PostgreSQL database for reliable data management
  • Responsive design with Tailwind CSS

What I Learned

This project deepened my understanding of full-stack development, particularly implementing secure session-based authentication, designing relational databases, and creating dynamic, responsive user interfaces with React and Tailwind CSS.

Space Invaders Game

Desktop Development

Project Overview

A desktop Space Invaders game built in C# using WPF, featuring classic arcade gameplay with modern enhancements. The game includes player movement, enemy waves, scoring systems, lives management, difficulty settings, and a leaderboard to track high scores.

What I Built

I designed and implemented the complete game from scratch, including game mechanics, collision detection, sprite animations, sound effects, and persistent user preferences. Built a smooth game loop for responsive gameplay.

Technologies & Tools Used

C# WPF OOP Principles Visual Studio XAML

Key Features

  • Player movement and shooting mechanics
  • Enemy wave patterns and AI behavior
  • Scoring and lives system
  • Multiple difficulty settings
  • Leaderboard with persistent high scores
  • Sprite animations and visual effects
  • Sound effects with customizable settings
  • Smooth collision detection
  • Persistent user preferences across sessions

What I Learned

This project strengthened my understanding of object-oriented programming principles including interfaces, inheritance, and encapsulation. I gained experience in game loop implementation, collision detection algorithms, and creating maintainable, reusable code structures.
